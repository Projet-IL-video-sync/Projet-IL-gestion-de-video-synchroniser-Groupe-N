# Décisions techniques

## Next.js

Next.js a été choisi comme framework principal du projet.

Il permet de développer l'application avec React tout en fournissant une structure pour les pages, le routage et les fonctionnalités côté serveur.

Le projet utilise l'App Router de Next.js.

## JavaScript

Le projet utilise JavaScript plutôt que TypeScript.

Ce choix permet de limiter la complexité technique et de faciliter la prise en main du projet par l'ensemble du groupe, les niveaux en développement pouvant être différents.

Les fichiers contenant du JSX utilisent l'extension `.jsx`.

## React

React est utilisé pour construire l'interface utilisateur de l'application.

L'interface sera composée de composants réutilisables afin de faciliter l'organisation et la maintenance du code.

## Tailwind CSS

Tailwind CSS est utilisé pour la mise en forme de l'interface.

Il permet de définir les styles directement dans les composants et d'éviter de multiplier les fichiers CSS pour les différents éléments de l'application.

## ESLint

ESLint est utilisé pour analyser le code JavaScript et détecter certaines erreurs ou pratiques problématiques.

Il permet également de conserver une certaine cohérence dans le code du projet.

## App Router

Le projet utilise l'App Router fourni par Next.js.

Les différentes pages de l'application seront organisées à partir de l'arborescence du dossier `src/app`.

## React Compiler

Le React Compiler n'est pas activé actuellement.

Ce choix permet de conserver une configuration simple pendant la phase initiale du développement.

Son utilisation pourra être réévaluée ultérieurement si elle présente un intérêt pour le projet.
