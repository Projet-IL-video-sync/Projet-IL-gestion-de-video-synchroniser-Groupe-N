# Installation du projet

## Prérequis

Avant d'installer le projet, il faut disposer de :

- Git
- Node.js
- npm

Les versions exactes pourront être précisées ultérieurement si le projet nécessite une version particulière de Node.js.

## Récupérer le projet

Cloner le dépôt :

`git clone https://github.com/NassimBenchenni/Projet-IL-gestion-de-video-synchroniser-Groupe-N.git`

Entrer dans le dossier du projet :

`cd Projet-IL-gestion-de-video-synchroniser-Groupe-N`

## Installer les dépendances

Installer les dépendances du projet avec :

`npm install`

## Lancer le serveur de développement

Pour lancer le projet en développement :

`npm run dev`

Le projet est ensuite accessible à l'adresse :

`http://localhost:3000`

## Arrêter le serveur

Pour arrêter le serveur de développement :

`Ctrl + C`

## Développement

Les modifications effectuées dans le projet sont automatiquement prises en compte par Next.js pendant que le serveur de développement fonctionne.

Avant de pousser des modifications, il est recommandé de vérifier que le projet démarre correctement et que les fonctionnalités modifiées fonctionnent comme prévu.
