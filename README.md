# Plateforme de vidéos synchronisées

Projet universitaire de développement d'une plateforme web permettant à plusieurs utilisateurs de regarder des vidéos ensemble de manière synchronisée.

## Technologies

- Next.js
- React
- JavaScript
- JSX
- Tailwind CSS
- ESLint

## Développement

Installer les dépendances :

`npm install`

Lancer le serveur de développement :

`npm run dev`

L'application est accessible sur `http://localhost:3000`.

## Documentation
